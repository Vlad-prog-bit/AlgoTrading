# Алготрейдинг — AlgoTrading

Исследовательский Python-проект: финансовый RAG для работы с финансовыми документами и формирования проверяемых торговых гипотез, с последующей оценкой признаков и стратегий на исторических данных.

## Планируемые компоненты

- **BGE-M3** — эмбеддинги для поиска релевантных фрагментов документов.
- **Qwen** (в обсуждении — Qwen2.5-14B) — анализ найденного контекста и формулирование гипотез с указанием источников.
- **Торговые гипотезы** — явные предположения, условия проверки и измеримые критерии оценки.
- **CatBoost** — будущие эксперименты с табличными признаками и прогнозными моделями.
- **Бэктестинг** — проверка гипотез на исторических данных с временным разделением выборок, учётом комиссий и предотвращением утечки будущей информации.

Это план развития, а не готовая торговая система. Сейчас создан только каркас: модели, данные, парсинг, RAG и ML не добавлены и не реализованы. Библиотеки для будущей реализации установлены; веса моделей не скачивались.

## Локальное окружение

Требуется Python 3.11 или новее. Локальное Conda-окружение `.venv` создано; библиотеки установлены. Версии прямых зависимостей указаны в `pyproject.toml`, полный снимок окружения — в `requirements-lock.txt` (Python 3.11, macOS Apple Silicon). Позже, из папки проекта, можно создать изолированное окружение одним из способов.

Обычный Python:

```bash
python3.11 -m venv .venv
source .venv/bin/activate
```

Или Conda, если она уже установлена:

```bash
conda create --prefix ./.venv python=3.11 -y
conda activate ./.venv
```

Затем установить сам пакет в режиме разработки:

```bash
python -m pip install -e .
```

Команда устанавливает каркас пакета; скачивание моделей и настройка RAG в неё не входят. Для сборки используется setuptools.

## Открытие в редакторе

В VS Code выберите **File → Open Folder…** и откройте папку `AlgoTrading`. Если команда `code` настроена, можно выполнить `code .` из этой папки. После создания окружения выберите `.venv/bin/python` через **Python: Select Interpreter**.

В Codex откройте эту же локальную папку как проект. Все файлы каркаса — обычные текстовые файлы UTF-8.

## Установленные инструменты

- Видео: yt-dlp, openai-whisper и локальный FFmpeg через imageio-ffmpeg.
- Данные: NumPy, pandas, SciPy, PyArrow; графики: Matplotlib, Seaborn, Plotly.
- ML и RAG: scikit-learn, CatBoost, PyTorch, Transformers, sentence-transformers, FAISS CPU.
- Документы и веб: pypdf, PyMuPDF, BeautifulSoup, lxml, requests, httpx.
- Исследования и разработка: JupyterLab, ipykernel, pytest, Ruff.
- Конфигурация: PyYAML, Pydantic, python-dotenv. Бэктестинг: backtesting.

Активация из терминала:

```bash
conda activate ~/Desktop/AlgoTrading/.venv
```

FFmpeg доступен после активации окружения. Загрузка моделей вызывается отдельно и не выполнялась при установке библиотек.
